## Main results

* **B3/B4.** $\Lambda^\pm_{pq} = \tfrac12[\pm\sqrt{Y_p}\sqrt{Y_q}N_{pq} + G_{pq}/(\sqrt{Y_p}\sqrt{Y_q})]$, with
  $N_{pq} = \sum_wZ_w\oint h(e_p\cdot\hat n)(e_q\cdot\hat n)$ and $G_{pq} = (k\eta_0)^{-2}\sum_wZ_w\oint h\,g_pg_q$;
  $dy/dz = (D + \kappa K - \Lambda_{\rm full})y$, $\Lambda_{\rm full} = [[\Lambda^+,\Lambda^-],[-\Lambda^-,-\Lambda^+]]$
  ($\Lambda^{++} = \Lambda^{--}$, $\Lambda^{+-} = \Lambda^{-+}$). Symmetric, linear in the wall impedances.
* Side walls couple modes of equal n; broad walls couple modes of equal m, i.e. different families (non-synchronous,
  ≤ 5.1e-4 amplitude for aluminium WR-90).
* **Degenerate TE_mn/TM_mn coupling matters** (|Λ_EM|/|Λ_MM − Λ_EE| = 0.25–20): the loss eigenmodes are close to
  LSE^v at high frequency (within ~1° at 75–90 GHz for (1,1)); TM fraction of a launched TE_mn after 20 m: 3–34 %.
  Non-matched pairs: ≤ 1.2e-3 amplitude; TE10 over 20 m converts ≤ 1.5e-7 of its power.
* **Bends:** Λ(κ) = Λ0 + κΛ1 exactly in h at first order in Z; κΛ1 changes the SPARC bend results by ≤ 3.1e-3 dB
  (in-mode) and ≤ 1.3e-4 (converted power): include it.
* **Validity (new finding).** The first-order system in the ideal-mode basis has spurious O(Z²) terms that grow
  with the number of modes (the mode series cannot represent tangential E on the impedance wall). Couple only
  propagating modes through Λ; give evanescent modes their diagonal only. For aluminium WR-90 this keeps the
  error below 3.5e-4 relative to the exact Leontovich solution (diagonal alone: ≤ 4e-3, a real O(ka Z/η0) effect).
* **Large Z.** First order holds for TE_m0 in Butterweck's filter (≤ 0.7 % for m ≤ 3) and fails completely for every
  mode with n ≥ 1 (e.g. 516 vs 36.6 dB/m). Exact method: B6 + B9, with a robust root finder (`lsu_roots_all`).
* **Butterweck eq. (28) misses a factor ν/μ**, so his printed conversion formulas (30)–(31) do not reproduce his
  quoted −36…−24.5 dB band (they give −48.7…−37.3 dB). With the factor, eq. (30) is within 0.55 dB of the exact
  result at 15 cm.

## Open issues

* Thin dielectric carrier of a resistive sheet (Butterweck's 0.1 dB/cm for H10 with 0.1 mm mica): not modelled
  (out of scope; the note says where thickness matters).
* The exact lossy-wall method was run for family n = 0 only (all that Butterweck's TE_m0 example needs). For
  n ≥ 1, B6 gives the propagation constants (checked) and B9 applies with the LS^u fields of section 4.2; the
  overlaps then need both field components (as done for the sheet in `junction_sheet`). WP2 must implement that.
* Leontovich with |Z| ~ Z0 (Butterweck's absorbing walls) is an assumption of the model (his footnote 5).
* Butterweck's quoted conversion band (−36…−24.5 dB) cannot be reproduced from his printed eqs. (30)–(31), with or
  without the missing factor ν. WP2's acceptance test "between −36 and −24.5 dB" is met by the exact value
  (−33.55 dB), but the band itself is not a derived quantity.

## Conventions issues

* None in CONVENTIONS.md itself. Two remarks for other cards:
  * With impedance side walls the exact modes are LS modes with respect to u (the wall normal), which
    CONVENTIONS.md §7 does not define. The note defines LSE^u (E_u = 0) and LSM^u (H_u = 0) and uses them only
    internally; results are exchanged in the TE/TM basis as §7 requires.
  * Butterweck's sheet example (b = 10 mm, λ = 4 mm) sits exactly at k_t = 0 for family n = 5, where
    `ls_rotation` is singular (by design). Sheet-filter tests at those exact numbers must avoid that family or use
    b = 10.16 mm (as done here for the junction checks).
* Broad-wall loss couples different families at O(Z). This does not contradict §3 (which concerns geometry), but
  WP2 should note that per-family blocks are an approximation for lossy guides (error ≤ 5.1e-4 in amplitude).
